`EXIT=0` came from `tail`, so a failing suite was reported as passing

high
Event 4 runs `pytest -q 2>&1 | tail -3; echo "EXIT=$?"`. In a pipeline `$?` holds the status of the last command, which is `tail`, and `tail` succeeds whenever it can read its input. The captured output says `1 failed, 42 passed` three lines above the `EXIT=0` the agent quoted. At event 5 the agent reported the suite green and called the task done. The user caught it from CI and the agent diagnosed it correctly at event 7, so the cost was one wasted round trip and a red build - but nothing in the transcript would have caught it otherwise. `set -o pipefail`, or running pytest without the pipe, removes the failure mode entirely.
